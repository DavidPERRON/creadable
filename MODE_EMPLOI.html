1. Concept et objectif

Problème : Identifier parmi 94 banques européennes lesquelles sont prêtes à acheter une solution de Supply Chain Finance / Trade Finance dans les 6 à 18 prochains mois — sans équipe de recherche de 10 personnes.

Solution : CredAble Intelligence automatise la due diligence sur deux axes :
  1. Côté corporate (demande) — Analyser les rapports annuels de 224 grandes entreprises européennes pour extraire leurs usages SCF, leurs banques partenaires et leurs signaux de besoin.
  2. Côté banque (offre) — Scorer 94 banques sur 8 signaux d'achat (tech stack, signaux stratégiques, failures fintech, pression concurrentielle…) pour produire un classement de priorité.

1.1 Le moteur de scoring — BIS (Buying Intent Score)

Le BIS est un score composite 0–100 calculé pour chaque banque :

#SignalPoidsSource
1Capability gap SCF20%Rapport annuel banque (LLM)
2Strategic intent digital/fintech15%Rapport annuel + news (LLM)
3Fintech failure / plateforme orpheline20%fintech_failures.json
4Pression concurrentielle pairs10%competitor_intelligence.json
5Demande corporate mesurée10%Extractions corporates (LLM)
6Pré-intégration ERP/SAP15%Tech stack + extractions
7Partenariat TCI (assurance-crédit)5%Tech stack
8Signaux de stress financier5%Rapport annuel (LLM)

1.2 Univers cible

PérimètreNombreCritères
Corporates analysés224EU, €1–25bn+ CA, industrie/manufacturing (pas de services)
Banques scorées94EU — banques faisant du trade finance
Dont trade finance confirmé49Signal TF extrait des rapports annuels
Dont friction déploiement LOW26Quick wins CredAble

1.3 Périmètre de l'extraction LLM

Le LLM analyse uniquement les passages pertinents des rapports annuels officiels (PDF → texte → chunks filtrés par mots-clés SCF). Il s'appuie sur sa connaissance générale pour contextualiser — mais ne fabrique aucun chiffre ou fait non présent dans le document.
Inclus par défautOptionnel (enrichissements)
Rapport annuel officiel (texte brut)Actualités web (DuckDuckGo full-text)
Connaissance générale du LLMCross-référence entre corporates
Tech stack curé (94 banques)Offres d'emploi (signal recrutement)
Signaux V4 (failures, concurrents)Prédictions LLM P(achat)

2. Démarrage

2.1 Démarrage normal

Finder → Bureau → dossier creadable → double-clic sur Start CredAble.command

Le script fait automatiquement : mise à jour Git, vérification npm, démarrage serveur, ouverture navigateur.

Premier lancement : macOS peut bloquer le fichier. Clic droit → Ouvrir → confirmer.

2.2 Démarrage depuis le terminal

cd ~/Desktop/creadable
git pull
npm run ui

2.3 Redémarrage propre

pkill -f "node ui/server.js"
git pull
npm run ui
Navigateur : Toujours utiliser http://localhost:3333 (pas https). Si Safari force HTTPS : Safari → Réglages → Avancé → décocher "Utiliser automatiquement HTTPS".

7. Enrichissements optionnels

7.1 Actualités web (news)

Le module news fetche 3 requêtes DuckDuckGo par entité (banque ou corporate) et visite chaque article pour en extraire le corps complet (~3000 caractères/article, jusqu'à 6 articles).

Requêtes pour les banques :

  • "[Banque]" digital transformation trade finance 2025
  • "[Banque]" fintech SCF working capital platform
  • "[Banque]" CEO appointment merger acquisition fintech

Signaux détectés dans les articles : platform_or_tech, fintech_partnership, ceo_or_exec_change, digital_initiative, merger → chaque signal ajoute des points au score BIS strategic_intent.

Cache : 7 jours. Utiliser --force pour rafraîchir.

7.2 Offres d'emploi (jobs)

Recherche les recrutements SCF/TF pour chaque banque via DuckDuckGo.

Intent LevelRôles détectésImpact BIS
VERY_HIGHHead of SCF, Director Trade Finance, VP Supply Chain Finance+3 pts
HIGHSCF Specialist, Trade Finance Analyst, Working Capital Manager+2 pts
MEDIUMTransaction Banking, Cash Management, Treasury+1 pt

Cache : 3 jours (les offres changent plus vite que les news).

7.3 Cross-référence corporates

Après toutes les extractions corporates, crossref.js agrège :

  • Top banques par nombre de citations — ex: "BNP Paribas cité par 18 corporates dans un contexte SCF" = signal de demande fort
  • Plateformes détectées — Taulia, C2FO, Orbian… et leur fréquence
  • Taux SCF par secteur — % de corporates avec activité SCF confirmée dans chaque secteur

Résultat : corporate_scraper/reports/crossref.json + crossref.md

7.4 Signal de demande corporate

demand_signal.js score chaque corporate sur P(pousse sa banque à adopter SCF en 12 mois) :

CritèrePoints
Produit SCF avec confidence HIGH+3
Produit SCF avec confidence MEDIUM+2
≥5 banques mentionnées dans contexte SCF+3
ERP intégration confirmée (SAP/Oracle)+2
SCF lié ESG+2
Plateforme concurrente déjà présente-2 (déjà servi)

8. Mode Prédiction

Le mode prédiction utilise le LLM 405B pour synthétiser tous les signaux disponibles et produire une estimation structurée de la probabilité d'achat — avec fenêtre optimale et angle d'approche recommandé.

8.1 Prédictions bancaires

Sidebar → BIS Scores → cocher "Mode prédiction" → cliquer "Générer prédictions (LLM)"

Pour chaque banque, le LLM reçoit : score BIS, détail des 8 signaux, tech stack, pitch argument — et génère :

ChampDescription
p_buy_6mProbabilité d'achat à 6 mois (0–100%)
p_buy_12mProbabilité d'achat à 12 mois (0–100%)
p_buy_18mProbabilité d'achat à 18 mois (0–100%)
optimal_windowFenêtre optimale d'approche (ex: Q2 2026)
top_triggerÉvénement à surveiller (ex: "Renouvellement Roger Global → décision imminente")
pitch_angleAngle d'approche recommandé pour le premier contact
prediction_confidenceHIGH / MEDIUM / LOW (fiabilité de la prédiction)
Sans clé API : mode algorithmique automatique (sigmoid sur BIS score). Moins riche mais instantané et gratuit.
Avec clé API : LLM 405B — coût ~$0.10 pour les 94 banques.

8.2 Signal de demande corporate

Pipeline → cocher "Signal de demande corporate" → cs:demand

Score P(push SCF en 12 mois) par corporate. Résultat dans reports/demand_signals.json.

NiveauP(12m)Signification
VERY_HIGH~80%Programme SCF actif + multiples banques + ERP intégré
HIGH~60%Activité SCF confirmée, engagement bancaire multiple
MEDIUM~35%Signaux partiels — SCF mentionné sans confirmation forte
LOW / NONE<20%Peu ou pas de signaux SCF dans le rapport annuel

11. Dépannage

ProblèmeSolution
Safari force HTTPSSafari → Réglages → Avancé → décocher "Utiliser automatiquement HTTPS". Ou Chrome avec http://localhost:3333.
Dashboard blanc (écran vide)L'iframe se recharge à chaque visite. Si vide : (1) vérifier que les extractions existent, (2) relancer Aggregate, (3) ouvrir le fichier .html directement depuis le Finder.
Extraction FAIL — timeoutL'API DeepInfra a dépassé le délai. Relancer depuis la page Extractions → Re-extraire. Si systématique, vérifier la clé API.

FAIL — download_failed (banques)Normal — rapport derrière login. La banque sera scorée via les autres signaux.

DEEPINFRA_API_KEY non configuréeSidebar → Configuration → coller la clé → Enregistrer.
Le Mac s'endort pendant un long runLancer avec caffeinate -i node engine/extractor.js (empêche le sleep).
111 extractions, plus rienNormal — l'extracteur a traité tout ce qui a un fichier .txt. Lancer Download PDFs pour les nouveaux corporates.

12. Flux de travail recommandé

12.1 Premier lancement complet

  1. Double-clic Start CredAble.command → ouvre http://localhost:3333
  2. Sidebar → Configuration → saisir clé DeepInfra → Enregistrer (témoin vert)
  3. Pipeline → Download PDFs → attendre (1–3h, laisser le Mac ouvert)
  4. Pipeline → Extract → attendre (1–3h) — utilise 4 workers en parallèle
  5. Pipeline → Aggregate → génère le dashboard corporate
  6. BIS Scores → Télécharger PDFs banques → 30–60 min
  7. BIS Scores → Actualiser news banques → 30 min (optionnel mais recommandé)
  8. BIS Scores → Scanner offres d'emploi → 15 min (optionnel)
  9. BIS Scores → Extraire rapports banques → 1–2h
  10. BIS Scores → Recalculer BIS + rapport → 30 secondes
  11. Consulter BIS Dashboard et Dashboard Corporate

12.2 Mise à jour hebdomadaire

  1. git pull && npm run ui
  2. Actualiser news banques + Scanner offres d'emploi
  3. Recalculer BIS + rapport
  4. Si nouveaux rapports annuels disponibles : Download PDFs → Extract → Aggregate

12.3 Avant une présentation

  1. Recalculer BIS + rapport → BIS Dashboard
  2. Activer Mode prédiction → Générer prédictions
  3. Utiliser le curseur "Seuil min." pour filtrer les banques pertinentes
  4. Ouvrir le BIS Dashboard directement depuis le Finder pour la présentation
Idempotence : Toutes les étapes peuvent être relancées sans risque — les fichiers déjà traités sont sautés automatiquement (CACHED). Pour forcer le re-traitement : utiliser "Re-extraire" dans la page Extractions, ou --force en ligne de commande.
