1. Vue d'ensemble

CredAble Intelligence est une plateforme d'analyse automatisée qui :

  • Télécharge les rapports annuels des 159 plus grandes entreprises européennes (>5 Md€ CA)
  • Extrait via LLM les signaux trade finance / supply chain finance (factoring, confirming, lettres de crédit, plateformes SCF…)
  • Score 51 banques européennes sur 8 signaux (BIS — Buying Intent Score)
  • Génère des dashboards interactifs pour cibler les prospects prioritaires
Principe : Le rapport annuel est une source parmi d'autres. Les données tech stack banques, les signaux fintech failures, l'intelligence concurrentielle et le scoring BIS restent inchangés — le LLM enrichit la couche corporate.

2. Démarrage de l'application

2.1 Démarrage normal (double-clic)

Finder → Bureau → dossier creadable → double-clic sur Start CredAble.command

Le script fait automatiquement :

  1. Mise à jour du code depuis Git
  2. Installation / vérification des dépendances npm
  3. Ouverture du navigateur sur http://localhost:3333
  4. Démarrage du serveur
Premier lancement : macOS peut bloquer le fichier. Si un message "impossible d'ouvrir" s'affiche → clic droit → Ouvrir → confirmer.

2.2 Démarrage depuis le terminal (alternative)

cd ~/Desktop/creadable
npm run ui

Laisser cette fenêtre ouverte. Le serveur tourne tant qu'elle est ouverte.

2.3 Accès dans le navigateur

Toujours utiliser Safari et taper manuellement http://localhost:3333 (pas https). Si Safari force HTTPS : Safari → Réglages → Avancé → décocher "Utiliser automatiquement HTTPS".

3. Configuration initiale

3.1 Clé API DeepInfra

L'étape d'extraction LLM nécessite une clé API DeepInfra.

  1. Dans la sidebar → Configuration
  2. Coller la clé dans le champ DEEPINFRA_API_KEY
  3. Cliquer Enregistrer
  4. Le témoin en bas à gauche passe au ● vert
La clé est stockée en mémoire serveur uniquement (non persistée sur disque). Elle doit être re-saisie à chaque redémarrage du serveur.

4. Pipeline Corporate Scraper

Le pipeline comporte 4 étapes séquentielles. On peut les lancer individuellement ou d'un seul clic.

ÉtapeBouton UIDurée estiméeDescription
1 — DiscoverDiscover URLs5–10 minRemplit les URLs directes des rapports PDF dans le catalogue
2 — DownloadDownload PDFs30–60 minTélécharge les PDFs + extrait le texte brut
3 — ExtractExtract (LLM)60–120 minEnvoie les passages SCF au LLM pour extraction structurée
4 — AggregateAggregate2–5 minCompile les résultats, génère summary + dashboard

4.1 Pipeline complet (recommandé)

Sidebar → Pipeline → bouton "Lancer pipeline complet" — enchaîne les 4 étapes automatiquement.

4.2 Étapes individuelles

Les boutons individuels sont utiles pour relancer une étape sans repartir de zéro. Chaque étape est idempotente : elle saute les fichiers déjà traités.

4.3 Extraction par corporate

Pour analyser un seul corporate :

  1. Saisir l'ID dans le champ (ex: volkswagen, nestle, total-energies)
  2. Cliquer "Extraire ce corporate"
  3. Les logs s'affichent en temps réel

4.4 Logs en temps réel

La fenêtre "Logs en temps réel" affiche la sortie du processus en direct :

  • Texte gris = stdout normal
  • Texte orange = stderr / avertissements
  • ✓ Terminé avec succès = exit 0
  • ✗ Terminé avec erreur = problème à investiguer

5. Résultats d'extraction LLM

5.1 Consulter les extractions

Sidebar → Corporate Scraper → Extractions

  • Liste de tous les fichiers extraits, triés par date
  • Voir → affiche le JSON structuré complet
  • Re-extraire → relance l'analyse LLM pour ce corporate

5.2 Structure d'une extraction

Chaque extraction JSON contient :

ChampDescription
scf_program_confirmedPrésence confirmée d'un programme SCF (boolean)
scf_program_detailsDétails textuels du programme détecté
factoring_or_receivablesSignaux côté receivables (cession, affacturage…)
trade_finance_instrumentsL/C, garanties, documentary trade
platform_provider_mentionedPrésence d'un concurrent (Taulia, C2FO, Orbian…)
banks_mentioned_in_scf_or_trade_finance_contextBanques citées dans le contexte SCF
working_capital_kpisDPO, DSO, DIO si mentionnés
sweet_spot_scoreScore 0–10 indiquant l'attractivité pour CredAble
sweet_spot_rationaleJustification du score

5.3 Dashboard Corporate

Sidebar → Corporate Scraper → Dashboard — rapport HTML interactif après l'étape Aggregate. Inclut le classement sweet-spot, les signaux détectés, la méthodologie.

6. Bank Intelligence — Scores BIS

6.1 Qu'est-ce que le BIS ?

Le Buying Intent Score agrège 8 signaux pondérés pour estimer la probabilité qu'une banque achète une solution CredAble dans les 12 mois :

SignalPoidsSource
Capability gap SCF25%Rapport annuel banque (LLM)
Strategic intent20%Rapport annuel banque (LLM)
Tech stack legacy15%Données curées bank_techstack.json
Fintech failure orpheline15%fintech_failures.json
Concurrent absent10%competitor_intelligence.json
Fenêtre budgétaire8%bank_techstack.json
Friction CredAble4%bank_techstack.json
Signaux corporate3%Extractions corporate (LLM)

6.2 Buckets BIS

BucketScorePriorité
HIGH≥ 70Prospection immédiate
MEDIUM-HIGH50–69Pipeline Q2/Q3
MEDIUM30–49Nurturing
LOW / VERY LOW< 30Déprioritiser

6.3 Recalculer les scores

Sidebar → Bank Intelligence → BIS Scores → bouton "Recalculer BIS + rapport"

  • Lit les extractions banques + données curées
  • Recalcule tous les scores
  • Génère le BIS Dashboard HTML

6.4 Extraire les rapports banques

Même principe que pour les corporates — bouton "Extraire rapports banques (LLM)" ou extraction par ID banque (ex: kb-cz, bnp-fr).

7. Données et configuration avancée

7.1 Édition des fichiers JSON

Sidebar → Données → Fichiers JSON — éditeur direct des 4 fichiers de configuration :

FichierContenu
Tech Stack BanquesCore banking, plateforme SCF, fenêtre budgétaire, friction CredAble pour 51 banques
Fintech FailuresFaillites fintech et banques orphelines (Signal 3 BIS)
ConcurrentsIntelligence concurrentielle vérifiée (Demica, Orbian, Taulia…)
Catalogue Corporates159 corporates EU avec URLs des rapports annuels
Cliquer Sauvegarder après chaque modification. Le JSON est validé avant sauvegarde.

7.2 Changer le modèle LLM

Par défaut : meta-llama/Llama-3.3-70B-Instruct via DeepInfra. Pour utiliser un autre modèle, définir la variable d'environnement avant de lancer le serveur :

DEEPINFRA_MODEL=deepseek-ai/DeepSeek-V3 npm run ui

8. Dépannage

ProblèmeSolution
Safari force HTTPS sur localhost Safari → Réglages → Avancé → décocher "Utiliser automatiquement HTTPS". Ou taper http://localhost:3333 manuellement.
Start CredAble.command ne s'ouvre pas Clic droit → Ouvrir → Confirmer. Ou dans Terminal : chmod +x ~/Desktop/creadable/Start\ CredAble.command
Extraction FAIL — timeout Réseau lent ou modèle surchargé. Relancer l'extraction pour ce corporate depuis la page Extractions → Re-extraire.
SKIP — no txt available Le PDF n'a pas été téléchargé. Lancer d'abord Download PDFs, puis Extract.
DEEPINFRA_API_KEY non configurée Aller dans Configuration → saisir la clé → Enregistrer. Le témoin doit passer au vert.
Le serveur ne répond plus Fermer la fenêtre Start CredAble.command et la rouvrir, ou npm run ui dans Terminal.
Dashboard non généré Lancer l'étape Aggregate après les extractions. Le dashboard apparaît alors dans la sidebar.

9. Flux de travail recommandé

  1. Double-clic sur Start CredAble.command → ouvre http://localhost:3333
  2. Configuration → saisir la clé DeepInfra → vérifier le témoin vert
  3. Pipeline → Download PDFs → attendre la fin (logs "OK" ou "CACHED")
  4. Pipeline → Extract (LLM) → attendre (1–2h pour 159 corporates)
  5. Pipeline → Aggregate → génère le dashboard
  6. Corporate Scraper → Dashboard → consulter le classement sweet-spot
  7. Bank Intelligence → Recalculer BIS + rapport → scores mis à jour avec les nouveaux signaux
  8. Bank Intelligence → BIS Dashboard → rapport interactif pour la prospection
Idempotence : Toutes les étapes peuvent être relancées sans risque — les fichiers déjà traités sont automatiquement sautés. Pour forcer le re-traitement d'un corporate, utiliser "Re-extraire" dans la page Extractions.
