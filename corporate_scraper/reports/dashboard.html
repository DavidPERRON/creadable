🔬 Sources utilisées par le modèle DeepInfra

✅ Sources fournies au modèle (DeepSeek-V3)

Uniquement des extraits filtrés de rapports annuels corporates (PDF → texte → chunks par mots-clés).

  • Source : sites Investor Relations officiels des corporates listés dans catalog.json
  • Format : texte filtré par ~120 mots-clés multilingues (working capital, factoring, supplier finance, letter of credit, inventory, cession de créances, Akkreditiv, etc.)
  • Volume : ~25K tokens par corporate (vs ~500K tokens dans le PDF complet)
  • Modèle : DeepSeek-V3 via DeepInfra, température 0.0 (déterministe)

❌ Sources INTERDITES au modèle

Le prompt système contient cette consigne stricte :

"Only extract what is EXPLICITLY stated in the text. Never infer, assume, or hallucinate. Always provide the verbatim quote."
  • Pas d'accès web (DeepInfra n'expose pas cette capacité)
  • Pas de training data (interdit par consigne)
  • Pas de cross-reference entre corporates (chaque appel isolé)
  • Pas d'autres rapports / press / news

Garde-fou : chaque "fait" extrait est accompagné d'un verbatim. Tu peux vérifier en cherchant la phrase exacte dans text/<corp>.txt.

ℹ️ Sources externes utilisées par d'AUTRES modules (PAS par DeepInfra)

L'écosystème complet utilise plusieurs sources, mais aucune n'est fournie au modèle pour l'extraction des rapports annuels :

  • prospection/ : Aequitas Consultus, Allianz Trade Atlas 2026, Marsh PRR 2026, UN Comtrade, FCI
  • prospection/trigger_engine/ : RSS GTR, TFG, TXF, BAFT, FCI, EBRD, EIB, IFC
  • scraper/ : sites bancaires, salles de presse, recherches GTR/TFG/TXF
  • corporate_scraper/ (CE module) : uniquement les rapports annuels corporates filtrés

⚠️ Limitations honnêtes

  • LLM peut halluciner malgré la consigne → vérification possible via grep
  • Pré-filtre keywords pas exhaustif → liste extensible
  • PDFs scannés non extraits (OCR à ajouter)
  • Anti-bot sur certains sites IR → workflow manuel possible
  • Corporates privés (Bosch, Ferrero) hors périmètre
  • Couverture multi-langue partielle pour HU/RO/CZ/PL
